# Dynasty Dashboard

Live dynasty fantasy football dashboard for my Sleeper league. Power rankings, trade analyzer, playoff odds (Monte Carlo), waiver wire, draft capital, and a 3D player similarity galaxy.

Built as a single self-contained HTML file — React via CDN, Three.js for the galaxy, data live from the Sleeper API, no build step.

## Local use

Open index.html in a browser.

## Configure

Edit the LEAGUE_ID constant near the top of the script block.
